qwenGPU · tiny

A neural net, on a GPU, inside a neural net.

qwenGPU compiles a tiny computer into Qwen3.5-2B's layers: every token the model writes is one step of the machine. I wrote GPU kernels for it and ran a 5,296-parameter transformer on it, a model that makes up names.

The tricks

Doing transformer math on a GPU with no floats

The GPU has 4 lanes, 126 words of memory, 15 registers, one multiply per cycle and no division. So every kernel is integer arithmetic, designed around those limits.

matmul

Two int8 products in one multiply

weights0a₂0a₀
× inputx₀·x₂·
= bitsa₀x₀ + a₂x₂junk

Pack weights as a₀ + a₂·2¹⁶ and inputs as x₂ + x₀·2¹⁶. One 32-bit multiply puts a₀x₀ + a₂x₂ in the top half, exactly. A word of 4 weights costs 5 multiplier ops instead of 12.

softmax · SiLU

exp by squaring ten times

e^−x ≈ (1 − x/1024)^1024: one subtraction, then ten squarings, in fixed point. The orange line is the kernel's formula. The thick teal line under it is the real exp.

attention · SiLU

Division without a divider

Newton step1 / 1.7 ≈

No per-thread division, so 1/d is Newton's method: y ← y(2 − dy), from a linear first guess. Three steps hit full 32-bit precision. RMSNorm's 1/√ is a 15-step bitwise search.

What it writes

Names from the integer model

Trained on 32,000 names from Karpathy's makemore. One letter took 1h 43m inside Qwen, so these 16 names ran on the qgpu simulator, the same machine in plain Python. Every one matches the numpy version of the model.
